# P132 V0.2 — Lexicon Mapping Rules

Official vocabulary source entries are provenance records, not meanings.

## Cardinality

A source entry can map to zero, one, or several P132 Concepts. This is required for polysemy. A P132 Concept may also be supported by more than one external source entry.

## Review flow

Source Entry → Mapping Candidate → Approved Concept Mapping → Infiltration Suitability Review.

Mapping and infiltration suitability are independent decisions.

An exact English string match to an already-existing P132 form is approved by migration 08 only for the small set of concepts that already existed before the bulk import. New bulk-generated mappings must not receive automatic approval merely because strings match.

## Suitability

Mapped concepts start conservatively at C / Phase1Eligible=false until explicitly reviewed.

The reading engine must eventually use only approved mappings and Phase1Eligible concepts for new-learning vocabulary. Previously understood vocabulary is governed by learner state, not by the new-vocabulary quota.
