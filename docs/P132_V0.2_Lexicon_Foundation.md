# P132 V0.2 — Lexicon Foundation

## Decision

P132 English Shared Lexicon starts from the official 2,000-word reference vocabulary in Taiwan's 12-Year Basic Education English curriculum guidelines. The list contains the Basic 1,200 plus 800 other common reference words.

P132 does **not** treat every official word as automatically suitable for Phase 1 Progressive Immersion.

## Two independent layers

### Source layer
Preserves what the external source says:
- source identity
- source spelling
- Basic 1,200 flag
- Common 2,000 flag
- mapping/review status

### P132 infiltration layer
Records P132's own instructional decision:
- A — highly suitable for lexical infiltration
- B — suitable with ordinary contextual constraints
- C — context-sensitive
- D — unsuitable for Phase 1 lexical infiltration
- Phase1Eligible — operational switch used by the reading engine

An official curriculum tier must never be rewritten based on P132 suitability.

## Growth path

Official 1,200 Basic
→ Official additional 800 common words
→ P132 suitability review
→ approved Shared Lexicon
→ news-driven candidate growth beyond the official 2,000
→ reviewed promotion to Shared Lexicon

## Personal lexicon

Personal Lexicon / overlay remains a later phase. It must not mutate Shared Lexicon records.

Import the actual official English source entries into TblP132VocabularySourceEntry, preserving their official tier. Mapping them to ConceptID and assigning P132 suitability are separate review steps.
